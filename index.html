How to use Shadow Plugins

Using SS Plugins is easier than you might think. Follow these steps and you can set up your server in seconds:

  1. Download the plugin you want to use from our BuiltByBit page.
  2. Upload the plugin .jar to your Minecraft server's plugins folder.
  3. Restart your server. You should then see a new ShadowXXX folder generated.
  4. Open the Shadow folder and go to config.yml or license.yml. Paste the license key in the correct location. All Shadow Plugins use one unique license key.
key: "THE-LICENSE-KEY-HERE"

5. Finally, restart your server once again and the plugin should load.
